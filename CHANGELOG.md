## [0.1.0]

### Added

- Inline suggestions drawn over the prompt as you type, with ghost text for the first match and a list opened with Tab.
- Tab and Shift+Tab to move through suggestions, Enter to accept, Enter again to run, Esc to hide.
- Suggestions from PATH, shell built-ins, command specs, git branches and remotes, package.json scripts, Makefile targets and paths.
- Specs for git, gh, cargo, rustup, npm, yarn, pnpm, docker, kubectl, go, make, pip, brew, apt, dnf, pacman, winget, choco, scoop, systemctl, journalctl and common file commands.
- Support for bash, zsh, fish, PowerShell 7, Windows PowerShell and cmd on macOS, Linux and Windows.
- `autocomplete setup` and `autocomplete init` for startup files.
- Installers for `curl | sh` and `irm | iex`, release archives for six targets and a Homebrew formula.
